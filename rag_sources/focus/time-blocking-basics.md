## When to use

Use this when your day feels scattered or when you lose track of what you meant to do. It helps when you have several things to get done and want a simple way to assign them time instead of relying on memory or mood.

## Steps

1. **List what needs to happen today.** Write down tasks and commitments—meetings, errands, work items, rest. Do not worry about order yet.

2. **Estimate how long each will take.** Guess in 15- or 30-minute blocks. It is okay to be wrong; you can adjust. If something feels huge, give it one block and plan to revisit.

3. **Put blocks on a timeline.** Use a paper planner, calendar app, or simple list with times. “9–9:30 email,” “9:30–10:30 project X,” “10:30–11 break.” Include breaks and buffer—do not pack every minute.

4. **Start with the first block.** When the time comes, do that thing. If you get distracted, return to the block when you notice. You do not have to be perfect; the block is a guide, not a prison.

5. **Review at the end of the day.** What got done? What did not? What will you move to tomorrow? Use that to improve your estimates and blocks over time.

## Notes

- Time blocking works best when you build in flexibility. Leave gaps or “overflow” time so one overrun does not wreck the day.
- If blocking a full day feels like too much, start with 2–3 blocks—e.g., morning focus block, afternoon focus block—and add from there.
- This is practical coaching only, not treatment for ADHD or executive function difficulties.
